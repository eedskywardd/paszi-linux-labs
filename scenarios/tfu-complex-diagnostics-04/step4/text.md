# 4. Измерить оптическую мощность

Теперь определите, насколько велики потери.

Запустите:

```bash
power-meter F01
```

Обратите внимание на:

- длину волны;
- TX REFERENCE;
- RX POWER;
- TOTAL LOSS.

Запишите только величину общей потери:

```bash
echo "ЗНАЧЕНИЕ" > /root/tfu04/power.txt
```

Без единицы измерения.

После этого нажмите **CHECK**.
