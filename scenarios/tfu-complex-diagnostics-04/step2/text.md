# 2. Найти дефект медной линии L03

Проверьте L03 кабельным тестером:

```bash
cable-test L03
```

Определите:

- тип неисправности;
- номер проблемной жилы.

Теперь локализуйте дефект:

```bash
tdr L03
```

Создайте файл:

```bash
nano /root/tfu04/copper.txt
```

Заполните:

```text
LINE=
FAULT=
CONDUCTOR=
DISTANCE=
```

Значение DISTANCE записывайте числом без единицы измерения.

После заполнения нажмите **CHECK**.
