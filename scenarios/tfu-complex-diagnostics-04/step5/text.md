# 5. Локализовать событие с помощью OTDR

Теперь нужно понять, **где именно** возникает большая потеря в F01.

Запустите:

```bash
otdr F01
```

Найдите строку с крупным событием и определите:

- расстояние до события;
- величину потери;
- предполагаемый тип дефекта.

Создайте:

```bash
nano /root/tfu04/otdr.txt
```

Заполните:

```text
EVENT_DISTANCE=
EVENT_LOSS=
FAULT=
```

DISTANCE и LOSS записывайте только числом.

После этого нажмите **CHECK**.
