# 1. Первичная диагностика

Начните с общего состояния линий:

```bash
link-status
```

Найдите два сегмента, которые требуют дальнейшей диагностики.

Запишите их через пробел:

```bash
echo "XXX XXX" > /root/tfu04/suspects.txt
```

Проверьте:

```bash
cat /root/tfu04/suspects.txt
```

Один сегмент должен быть медным, второй — оптическим.

После этого нажмите **CHECK**.
