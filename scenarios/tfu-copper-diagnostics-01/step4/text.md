# 4. Оформить диагноз и восстановить линию

Создайте файл `/root/tfu01/report.txt`.

В нём должны быть эти поля:

```text
LINE=
FAULT=
CONDUCTOR=
DISTANCE=
```

Заполните их по результатам измерений.

Можно открыть редактор:

```bash
nano /root/tfu01/report.txt
```

Проверьте:

```bash
cat /root/tfu01/report.txt
```

Если диагноз правильный, выполните виртуальный ремонт:

```bash
repair-line L02
```

После ремонта обязательно сделайте контрольные измерения:

```bash
link-status
cable-test L02
tdr L02
```

Линия должна перейти в `UP / 1000 Mbps`, wiremap — в `PASS`, а TDR больше не должен показывать дефект.

Когда всё восстановлено, нажмите **CHECK**.
