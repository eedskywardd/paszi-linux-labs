# 1. Определить проблемную линию

Первый принцип диагностики: **сначала определить симптом и проблемный сегмент**, а не разбирать всё подряд.

Получите состояние всех линий:

```bash
link-status
```

Изучите таблицу.

Создайте отметку о том, что вы определили неисправную линию. Вместо `LXX` укажите её настоящий номер:

```bash
echo "LXX" > /root/tfu01/problem-line.txt
```

Проверьте:

```bash
cat /root/tfu01/problem-line.txt
```

После этого нажмите **CHECK**.
