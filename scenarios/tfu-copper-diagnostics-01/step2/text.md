# 2. Проверить линию кабельным тестером

Теперь нужно понять **тип физической неисправности**.

Запустите виртуальный кабельный тестер для найденной линии:

```bash
cable-test L02
```

Читайте wiremap построчно:

- слева — контакт на основном блоке тестера;
- справа — куда приходит соответствующая жила;
- `OPEN` означает отсутствие электрической непрерывности.

После анализа сохраните номер проблемной жилы:

```bash
echo "НОМЕР" > /root/tfu01/conductor.txt
```

Вместо `НОМЕР` укажите число.

Нажмите **CHECK**.
