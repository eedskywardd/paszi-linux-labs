# 3. Локализовать дефект с помощью TDR

Кабельный тестер уже показал **что** произошло. Теперь нужно понять **где** находится повреждение.

Запустите TDR:

```bash
tdr L02
```

TDR оценивает расстояние до изменения импеданса линии по отражённому сигналу.

Сохраните расстояние до дефекта **только числом в метрах**, например `12.3`:

```bash
echo "РАССТОЯНИЕ" > /root/tfu01/distance.txt
```

После этого нажмите **CHECK**.
