# ТФУ №1 · Диагностика медной линии

Вы работаете техником СКС. После монтажа офисной сети одно рабочее место потеряло связь.

В этой лабораторной терминал играет роль **виртуального набора измерительных приборов**. Команды `link-status`, `cable-test`, `tdr` и `repair-line` имитируют работу с реальной линией связи.

## Объект

В серверной есть четыре медные линии:

```text
SW1
├── L01 → PC-01
├── L02 → PC-02
├── L03 → PC-03
└── L04 → AP-01
```

Поступила заявка:

> **PC-02 не имеет сетевого соединения.**

## Что нужно сделать

1. Проверить состояние линий.
2. Выбрать проблемную линию.
3. Проверить её кабельным тестером.
4. Использовать TDR для локализации дефекта.
5. Записать технический диагноз.
6. Выполнить виртуальный ремонт.
7. Убедиться, что Link восстановился.

На каждом этапе выполняйте команды самостоятельно и нажимайте **CHECK** только после получения требуемого результата.
