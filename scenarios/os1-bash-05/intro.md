# ОС05 · Bash: процессы, фоновые задачи и мониторинг

До этого вы работали с файлами, текстом, путями, правами и системной информацией.

Теперь переходим к тому, что происходит **во время работы Linux** — к процессам.

Процесс — это запущенная программа. У каждого процесса есть:

- **PID** — уникальный номер процесса;
- **PPID** — номер родительского процесса;
- состояние;
- команда, которая его запустила.

В этой работе вы будете запускать только **свои учебные процессы** и завершать только их.

> Не используйте `kill` для случайных PID, которые вы не создавали сами.

Проверьте стенд:

```bash
cat /root/BASH05_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/bash05/work
pwd
```

Должно быть:

```text
/root/bash05/work
```
