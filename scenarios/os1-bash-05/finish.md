# ОС05 завершена

Теперь вы умеете работать с процессами Linux из Bash.

| Команда | Назначение |
|---|---|
| `ps` | процессы текущего терминала |
| `ps -eo ...` | выбрать столбцы |
| PID | номер процесса |
| PPID | PID родительского процесса |
| `$$` | PID текущей оболочки |
| `&` | запуск в фоне |
| `$!` | PID последнего фонового процесса |
| `jobs -l` | фоновые задачи оболочки |
| `ps -p PID` | конкретный процесс |
| `kill PID` | отправить SIGTERM |
| `uptime` | время работы и нагрузка |
| `free -h` | использование памяти |
| `top -b -n 1` | однократный снимок процессов |

## Главное правило

Не завершайте случайный процесс только потому, что увидели его PID. Сначала определите, что это за процесс.

Следующая практика может продолжить Bash через **переменные, окружение, алиасы и первые собственные скрипты**.
