# 3. Запускаем задачу в фоне: `&` и `$!`

Команда:

```bash
sleep 5
```

занимает терминал на 5 секунд.

Если поставить `&`:

```bash
sleep 300 &
```

процесс запускается в фоне, а терминал сразу возвращается.

Переменная `$!` содержит PID последнего фонового процесса.

Выполните:

```bash
cd /root/bash05/work
sleep 300 &
echo $! > background_pid.txt
```

Посмотрите PID:

```bash
cat background_pid.txt
```

Проверьте процесс:

```bash
ps -p $(cat background_pid.txt)
```

`$(...)` означает: выполнить команду внутри скобок и подставить результат.

Нажмите **CHECK**.
