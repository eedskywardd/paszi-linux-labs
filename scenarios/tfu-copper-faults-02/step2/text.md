# 2. Диагностировать L02 и L03

Теперь используйте кабельный тестер:

```bash
cable-test L02
cable-test L03
```

Сравните номера контактов.

Запишите результаты в файл:

```text
L02=
L03=
```

Допустимые названия:

```text
MISWIRE
REVERSED_PAIR
```

Откройте:

```bash
nano /root/tfu02/faults.txt
```

После заполнения нажмите **CHECK**.
