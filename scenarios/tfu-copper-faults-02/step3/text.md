# 3. Найти SPLIT PAIR

Проверьте линию L04:

```bash
cable-test L04
```

Обычный wiremap показывает соответствие контактов `1→1, 2→2 ... 8→8`.

Но линия работает только на 100 Mbps и имеет ошибки.

Проверьте целостность витых пар:

```bash
pair-test L04
```

Определите тип неисправности и запишите его:

```bash
echo "ТИП_НЕИСПРАВНОСТИ" > /root/tfu02/split.txt
```

Используйте написание с подчёркиванием.

После этого нажмите **CHECK**.
