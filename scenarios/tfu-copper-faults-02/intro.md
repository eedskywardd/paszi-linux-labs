# ТФУ №2 · Ошибки распиновки и витых пар

В первой работе вы нашли обрыв линии и локализовали его с помощью TDR.

Теперь задача сложнее: физическая линия может быть подключена неправильно, но выглядеть почти рабочей.

На стенде четыре линии:

```text
SW1
├── L01 → PC-01
├── L02 → PC-02
├── L03 → PC-03
└── L04 → PC-04
```

Одна линия исправна. На трёх остальных спрятаны разные ошибки:

- неправильное соответствие контактов;
- перевёрнутая пара;
- разделённая витая пара.

Ваша задача — определить неисправности по результатам измерений.

На каждом этапе выполняйте команды и только потом нажимайте **CHECK**.
