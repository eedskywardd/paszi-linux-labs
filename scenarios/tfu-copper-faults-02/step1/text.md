# 1. Найти подозрительные линии

Сначала не используйте кабельный тестер. Посмотрите только состояние линий:

```bash
link-status
```

Обратите внимание на:

- `LINK`;
- скорость;
- количество ошибок.

Запишите **три подозрительные линии** через пробел:

```bash
echo "LXX LXX LXX" > /root/tfu02/suspects.txt
```

Проверьте:

```bash
cat /root/tfu02/suspects.txt
```

Нажмите **CHECK**.
