# 4. Время работы и оперативная память

## Сколько система работает?

```bash
uptime
```

Команда показывает время работы системы и нагрузку.

Так как значение постоянно меняется, просто посмотрите вывод на экран.

Создайте отметку, что команду вы выполнили:

```bash
echo "uptime checked" > /root/bash04/work/uptime_checked.txt
```

## Оперативная память

Выполните:

```bash
free -h
```

Ключ `-h` означает **human-readable** — удобные для человека единицы: MiB, GiB и т. п.

В выводе важна строка:

```text
Mem:
```

Она показывает общую, использованную и свободную память.

Сохраните снимок:

```bash
free -h > /root/bash04/work/memory.txt
```

Проверьте:

```bash
cat /root/bash04/work/memory.txt
```

Нажмите **CHECK**.
