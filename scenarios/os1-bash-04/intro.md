# ОС04 · Системная информация Linux

На предыдущих работах вы научились работать с файлами, путями, поиском и правами доступа.

Теперь задача другая: **узнать, что это за Linux-система и какие у неё ресурсы**.

Сегодня вы научитесь получать:

- имя текущего пользователя;
- имя компьютера;
- версию ядра Linux;
- архитектуру процессора;
- название дистрибутива;
- время работы системы;
- сведения об оперативной памяти;
- сведения о дисках и файловых системах;
- системные сведения из каталога `/proc`.

## Подготовка

Выполните:

```bash
cat /root/BASH04_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/bash04/work
pwd
```

Должно быть:

```text
/root/bash04/work
```

Во всей работе используйте этот каталог для создаваемых файлов.
