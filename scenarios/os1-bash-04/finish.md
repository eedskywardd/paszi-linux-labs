# ОС04 завершена

Теперь вы умеете собирать основные сведения о Linux-системе из командной строки.

## Команды занятия

| Команда | Что показывает |
|---|---|
| `whoami` | текущего пользователя |
| `id` | UID, GID и группы |
| `hostname` | имя компьютера |
| `uname -r` | версию ядра |
| `uname -m` | архитектуру |
| `uname -a` | общие сведения о ядре и системе |
| `cat /etc/os-release` | сведения о дистрибутиве |
| `uptime` | время работы и нагрузку |
| `free -h` | оперативную память |
| `df -h` | использование файловых систем |
| `lsblk` | диски и разделы |
| `/proc/cpuinfo` | сведения о процессоре |
| `/proc/meminfo` | сведения о памяти |
| `/proc/version` | сведения о версии ядра |

## Главное

Linux позволяет получать большой объём системной информации обычными командами и через виртуальные файлы в `/proc`.
