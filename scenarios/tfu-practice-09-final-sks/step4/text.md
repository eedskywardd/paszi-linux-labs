# 4. Рассчитать порты и коммутацию

Количество медных конечных подключений:

- 18 рабочих мест;
- 1 AP;
- 2 камеры.

Итого активных медных портов: посчитайте самостоятельно.

Добавьте **20% запаса**, округляя вверх.

Выберите ближайший стандартный коммутатор:

```text
24
48
```

Создайте:

```bash
nano /root/tfu09/ports.txt
```

Шаблон:

```text
ACTIVE_PORTS=
WITH_RESERVE=
SWITCH_PORTS=
PATCH_PANEL=
POE_PORTS=
OPTICAL_UPLINKS=
OPTICAL_CROSS=
CABLE_MANAGER=
```

Для логических полей используйте `YES`.

После заполнения нажмите **CHECK**.
