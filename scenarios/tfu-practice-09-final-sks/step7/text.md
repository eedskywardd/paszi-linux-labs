# 7. Составить паспорт СКС

Финальная сеть должна иметь краткий паспорт.

Создайте:

```bash
nano /root/tfu09/passport.txt
```

Шаблон:

```text
PROJECT=ENTERPRISE_SCS
WORKPLACES=
COPPER_STANDARD=
POE_DEVICES=
FIBER_BACKBONES=
PATCH_PANEL=
SWITCH_PORTS=
LABELING=
DOCUMENTATION=
PROJECT_STATUS=
```

Используйте:

- WORKPLACES — количество рабочих мест;
- COPPER_STANDARD — основной стандарт линий рабочих мест;
- POE_DEVICES — количество PoE-устройств;
- FIBER_BACKBONES — количество магистралей;
- LABELING — `A-SCHEME`;
- DOCUMENTATION — `COMPLETE`;
- PROJECT_STATUS — `READY`.

После заполнения нажмите **CHECK**.
