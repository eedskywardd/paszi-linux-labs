# 6. Составить спецификацию

Теперь оформите итоговую ведомость основных материалов.

Создайте:

```bash
nano /root/tfu09/bom.txt
```

Шаблон:

```text
COPPER_CABLE_M=
PATCH_PANEL_48=
SWITCH_48=
POE_REQUIRED=
OPTICAL_CROSS=
MM_SFP_PAIRS=
SM_SFP_PAIRS=
F01_FIBER_M=
F02_FIBER_M=
CABLE_MANAGER=
```

Условия:

- общий рассчитанный медный кабель берите из этапа 3;
- одна патч-панель 48 портов;
- один коммутатор 48 портов;
- PoE требуется;
- один оптический кросс;
- на каждую оптическую магистраль нужна одна пара совместимых SFP;
- длины F01 и F02 уже известны;
- кабельный менеджмент требуется.

Для логических полей используйте `YES`.

После заполнения нажмите **CHECK**.
