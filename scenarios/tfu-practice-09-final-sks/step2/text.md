# 2. Обосновать кабельные решения

Теперь оформите краткое инженерное обоснование.

Создайте:

```bash
nano /root/tfu09/reasons.txt
```

Шаблон:

```text
ROOMS_REASON=
CAM02_REASON=
F01_REASON=
F02_REASON=
```

Используйте следующие ключевые формулировки:

```text
OFFICE_UNDER_100M
EMI_NEAR_POWER
INTERFLOOR_180M
REMOTE_BUILDING_620M
```

Нужно сопоставить каждое решение с соответствующей причиной.

После этого нажмите **CHECK**.
