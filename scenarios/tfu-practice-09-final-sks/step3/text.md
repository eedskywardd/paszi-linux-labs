# 3. Рассчитать кабельные трассы

Рассчитайте общий объём медного кабеля.

Исходные данные:

- кабинет 101: 10 линий × 42 м;
- кабинет 102: 8 линий × 55 м;
- AP-01: 76 м;
- CAM-01: 61 м;
- CAM-02: 67 м;
- запас кабеля: 10%.

Для самопроверки можно использовать:

```bash
route-calc
```

Создайте:

```bash
nano /root/tfu09/cable.txt
```

Шаблон:

```text
ROOM101=
ROOM102=
POE_TOTAL=
BASE_COPPER=
RESERVE_10=
TOTAL_COPPER=
F01_LENGTH=
F02_LENGTH=
```

Все значения указывайте в метрах, только числа.

После заполнения нажмите **CHECK**.
