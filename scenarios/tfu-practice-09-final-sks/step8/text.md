# 8. Сдать итоговый проект

Сначала просмотрите весь проект одной командой:

```bash
project-summary
```

Убедитесь, что у вас есть:

- `design.txt`;
- `cable.txt`;
- `ports.txt`;
- `labels.txt`;
- `bom.txt`;
- `passport.txt`.

Затем выполните:

```bash
final-project-check
```

Ожидаемый результат:

```text
PROJECT CHECK: PASS
СКС спроектирована и паспортизирована.
```

После успешной команды нажмите **CHECK**.
