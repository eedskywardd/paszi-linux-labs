# 5. Выбрать правильные действия по ремонту

Перед ремонтом оформите план действий.

Создайте:

```bash
nano /root/tfu06/actions.txt
```

Шаблон:

```text
L07_ACTION=
P12_ACTION=
F03_ACTION=
```

Выберите по одному действию из списка:

```text
RETERMINATE
REPLACE_CONTACT
CLEAN_OR_RESEAT_CONNECTOR
REPLACE_SWITCH
CHANGE_IP
REBOOT_PC
```

Выберите действие, которое соответствует **физической причине**, найденной на каждом сегменте.

После заполнения нажмите **CHECK**.
