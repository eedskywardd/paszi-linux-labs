# 3. Диагностировать PoE-порт P12

Камера CAM-02 перезапускается.

Сначала проверьте PoE:

```bash
poe-test P12
```

Затем проверьте линию под нагрузкой:

```bash
load-test P12
```

Создайте:

```bash
nano /root/tfu06/poe.txt
```

Шаблон:

```text
FAULT=
CAUSE=
```

Значения берите из вывода `load-test`.

После заполнения нажмите **CHECK**.
