# ОС09 завершена

Теперь вы умеете строить Bash-скрипты из отдельных логических блоков.

## Новые конструкции

| Конструкция | Назначение |
|---|---|
| `name() { ...; }` | объявить функцию |
| `name argument` | вызвать функцию с аргументом |
| `local X=value` | локальная переменная функции |
| `return 0` | успешный код возврата функции |
| `return 1` | код неуспеха |
| `case ... in` | выбрать одну ветку из нескольких |
| `*)` | ветка для остальных значений |
| `esac` | конец case |
| `read -r X` | прочитать ввод пользователя |

## Главное

Хороший скрипт не обязательно должен быть одной длинной последовательностью команд.

Теперь вы можете:

- вынести отдельные действия в функции;
- передавать функциям параметры;
- возвращать результат;
- выбирать функцию через case;
- строить простое интерактивное меню.
