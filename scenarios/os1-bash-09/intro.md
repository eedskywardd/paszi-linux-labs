# ОС09 · Bash: функции, case и интерактивное меню

В предыдущих работах вы уже умеете:

- создавать скрипты;
- принимать аргументы;
- использовать `if`;
- работать с циклами;
- обрабатывать несколько файлов.

Теперь научимся **делить большой скрипт на отдельные действия**.

Для этого нужны функции.

## Что такое функция

Функция — именованный блок команд.

Вместо повторения одного и того же кода несколько раз можно:

1. один раз описать функцию;
2. вызвать её по имени столько раз, сколько нужно.

Также сегодня появятся:

- `local` — локальная переменная функции;
- `return` — код возврата функции;
- `case` — удобный выбор одной ветки из нескольких;
- `read` — чтение ответа пользователя;
- простое текстовое меню.

## Подготовка

Проверьте стенд:

```bash
cat /root/BASH09_READY
```

Должно быть:

```text
READY
```

Перейдите в:

```bash
cd /root/bash09/work
pwd
```

Правильный путь:

```text
/root/bash09/work
```
