# 4. Рассчитать порты и компоненты СКС

На объекте:

- 24 ПК;
- 2 AP;
- 3 IP-камеры;
- 2 оптических uplink;
- нужен запас портов.

Для этой работы примите **20% запас по пользовательским медным портам**.

Сначала посчитайте активные медные подключения:

```text
24 + 2 + 3 = ?
```

Затем добавьте 20% запаса и округлите вверх до целого количества портов.

Подберите ближайшую стандартную ёмкость коммутации из вариантов:

```text
24
48
72
```

Создайте:

```bash
nano /root/tfu08/ports.txt
```

Шаблон:

```text
ACTIVE_COPPER=
WITH_RESERVE=
SWITCH_PORTS=
PATCH_PANEL=
OPTICAL_CROSS=
CABLE_MANAGER=
```

Для PATCH_PANEL используйте `48_PORT`, для двух последних логических полей — `YES`.

После этого нажмите **CHECK**.
