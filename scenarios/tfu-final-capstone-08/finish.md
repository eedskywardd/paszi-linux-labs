# ТФУ завершена

Это была финальная практическая работа курса.

За две пары вы прошли полный цикл работы с физическим уровнем:

## Проектирование

- выбрали Cat6 UTP для обычных рабочих мест;
- выбрали PoE-линии для AP и камер;
- предусмотрели экранирование возле силовой трассы;
- выбрали OM3 для межэтажной магистрали;
- выбрали OS2 для удалённого корпуса;
- рассчитали порты, патч-панель и элементы шкафа.

## Расчёты

Для F02 вы рассчитали:

- затухание волокна;
- потери на коннекторах;
- потери на сварках;
- инженерный запас;
- общие потери;
- ожидаемую мощность на приёмнике;
- пригодность линии по бюджету мощности.

## Диагностика

Вы использовали:

- кабельный тестер;
- TDR;
- PoE test;
- проверку под нагрузкой;
- VFL;
- Optical Power Meter;
- OTDR.

## Итог

Физический уровень считается принятым только тогда, когда:

1. проект соответствует условиям объекта;
2. расчёты показывают допустимые параметры;
3. линии проходят контрольные измерения;
4. все неисправности устранены;
5. итоговая приёмка показывает PASS.
