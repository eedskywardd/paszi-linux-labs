# 6. Найти неисправность медной линии L18

Перейдите от проектирования к аварийной части.

Посмотрите текущее состояние:

```bash
fault-status
```

Для линии L18 используйте подходящие приборы:

```bash
cable-test L18
tdr L18
```

Создайте:

```bash
nano /root/tfu08/copper-fault.txt
```

Шаблон:

```text
FAULT=
CONDUCTOR=
DISTANCE=
```

После заполнения нажмите **CHECK**.
