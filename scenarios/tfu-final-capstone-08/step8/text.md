# 8. Найти неисправность оптической линии F02

F02 поднята, но счётчик ошибок высокий.

Выполните диагностику последовательно:

```bash
vfl F02
power-meter F02
otdr F02
```

Сопоставьте результаты трёх приборов.

Создайте:

```bash
nano /root/tfu08/fiber-fault.txt
```

Шаблон:

```text
LOSS_DB=
EVENT_DISTANCE=
FAULT=
```

После заполнения нажмите **CHECK**.
