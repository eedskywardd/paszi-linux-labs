# 3. Спроектировать оптические магистрали

Условия:

- F01 — 160 м, между этажами одного здания;
- F02 — 680 м, отдельный корпус.

Для этой работы используйте:

```text
OM3_LC_MM_SFP
OS2_LC_SM_SFP
```

Создайте:

```bash
nano /root/tfu08/fiber-design.txt
```

Шаблон:

```text
F01=
F02=
```

После заполнения нажмите **CHECK**.
