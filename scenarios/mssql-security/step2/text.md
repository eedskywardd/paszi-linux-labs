# Этап 2. Кадровые данные доступны стажёру

`intern_user` ошибочно может читать `dbo.Employees`, а кадровик `hr_user` — не может. Исправьте оба нарушения.

**Критерии:** роль `hr_reader` и её участник могут читать кадровые записи; стажёр не может читать `dbo.Employees`, но сохраняет доступ к `dbo.PolicyBulletin`; никто из них не получает прав записи на кадровые данные.

<details><summary>Подсказка 1</summary>Одна роль лишена нужного разрешения, а у стажёра есть лишнее. Это две разные ошибки.</details>
<details><summary>Подсказка 2</summary>Один оператор выдаёт разрешение, другой отзывает ранее выданное: GRANT и REVOKE.</details>
<details><summary>Подсказка 3</summary>Проверяйте оба результата через EXECUTE AS USER: успешный SELECT у кадровика и отказ в чтении у стажёра. Затем REVERT.</details>
