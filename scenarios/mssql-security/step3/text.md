# Этап 3. Техническая поддержка видит закрытые комментарии

В `dbo.Tickets` у поддержки должны быть доступны лишь `ticket_id`, `status`, `summary`. Сейчас роль `ticket_reader` читает и закрытый столбец `internal_note`.

**Критерии:** `support_user` читает три разрешённых поля; `internal_note` и `SELECT *` недоступны; право SELECT на всю таблицу у роли `ticket_reader` отсутствует; права записи и исходные данные не меняются.

<details><summary>Подсказка 1</summary>Разрешение чтения всей таблицы слишком широкое. Используйте разрешения на отдельные столбцы.</details>
<details><summary>Подсказка 2</summary>Проверьте старый GRANT SELECT для таблицы целиком: его нужно отозвать. Затем выдать новое разрешение на конкретные поля.</details>
<details><summary>Подсказка 3</summary>Проверка как support_user: SELECT ticket_id,status,summary должен работать, а SELECT internal_note — возвращать отказ.</details>
