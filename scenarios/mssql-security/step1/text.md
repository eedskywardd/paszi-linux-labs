# Этап 1. Аналитик не видит журнал

Пользователь `analyst_user` состоит в роли `incident_reader`, но не может читать `dbo.Incidents`.

**Критерии:** роль `incident_reader` получает SELECT на `dbo.Incidents`; аналитик может читать журнал, но не может добавлять, изменять или удалять строки. Состав ролей и исходные данные сохраняются.

<details><summary>Подсказка 1 — диагноз</summary>Членство в роли само по себе ещё не даёт права на каждую таблицу. Проверьте разрешения самой роли.</details>
<details><summary>Подсказка 2 — инструмент</summary>В конспекте есть команда GRANT SELECT ON объект TO роль. Замените вымышленные имена нужными.</details>
<details><summary>Подсказка 3 — реальный тест</summary>Используйте EXECUTE AS USER = 'analyst_user'; затем SELECT TOP (1) ... FROM dbo.Incidents; и REVERT. На успешное чтение и отсутствие прав записи проверка смотрит отдельно.</details>

Когда закончите, нажмите **ПРОВЕРИТЬ**.
