# 6. Права числами: `755`, `644`, `600`

Права можно задавать не только буквами, но и числами.

Основные значения:

| Число | Право |
|---|---|
| 4 | чтение `r` |
| 2 | запись `w` |
| 1 | выполнение `x` |

Права складываются:

- `7 = 4 + 2 + 1 = rwx`;
- `6 = 4 + 2 = rw-`;
- `5 = 4 + 1 = r-x`;
- `4 = r--`;
- `0 = ---`.

Три цифры задают права для:

```text
владелец | группа | остальные
```

Например:

```text
755 = rwx r-x r-x
644 = rw- r-- r--
600 = rw- --- ---
```

Перейдите в нужный каталог:

```bash
cd /root/bash03/lab/permissions
```

Установите права:

```bash
chmod 755 run.sh
chmod 644 readme.txt
chmod 600 private.txt
```

Проверьте:

```bash
stat -c "%a %n" run.sh readme.txt private.txt
```

Теперь `run.sh` можно выполнить как программу:

```bash
./run.sh
```

Должно появиться:

```text
Bash 03 script works
```

Сохраните результат запуска:

```bash
./run.sh > /root/bash03/script_output.txt
```

Нажмите **CHECK**.
