# Bash 03 завершён

Теперь вы умеете ориентироваться в файловой системе, искать файлы и изменять базовые права доступа.

## Что вы изучили

| Команда / обозначение | Назначение |
|---|---|
| `pwd` | показать текущий каталог |
| абсолютный путь | полный путь от `/` |
| относительный путь | путь относительно текущего каталога |
| `.` | текущий каталог |
| `..` | каталог уровнем выше |
| `~` | домашний каталог |
| `find` | поиск файлов и каталогов |
| `find ... -type f` | искать файлы |
| `find ... -name` | искать по имени |
| `ls -l` | показать права доступа |
| `stat` | показать свойства файла |
| `chmod u+x` | добавить владельцу выполнение |
| `chmod o-r` | убрать чтение у остальных |
| `chmod 755` | rwx для владельца, r-x для остальных |
| `chmod 644` | владелец читает/пишет, остальные читают |
| `chmod 600` | доступ только владельцу |

## Главное правило

Если файл «пропал», сначала выполните:

```bash
pwd
ls -la
```

Очень часто файл не пропал — он просто был создан **в другом каталоге**.
