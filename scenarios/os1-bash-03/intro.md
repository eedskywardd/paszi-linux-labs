# Bash с нуля · занятие 3

На первых двух занятиях вы создавали файлы, копировали их и обрабатывали текст. Теперь нужно научиться **не теряться в файловой системе** и понимать, кто имеет доступ к файлам.

Сегодня:

| Команда / обозначение | Для чего |
|---|---|
| `pwd` | показать текущий каталог |
| `cd` | перейти в другой каталог |
| `.` | текущий каталог |
| `..` | родительский каталог |
| `~` | домашний каталог пользователя |
| `find` | найти файлы и каталоги |
| `ls -l` | показать подробную информацию и права |
| `chmod` | изменить права доступа |
| `stat` | показать свойства файла |

## Главное правило этого занятия

Перед созданием файла всегда задайте себе вопрос:

> **В каком каталоге я сейчас нахожусь?**

Проверить это можно командой:

```bash
pwd
```

Именно из-за неверного текущего каталога файл часто оказывается «не там».

## Подготовка

Выполните:

```bash
cat /root/BASH03_READY
```

Должно быть:

```text
READY
```

Посмотрите структуру учебного каталога:

```bash
cd /root/bash03/lab
find . -maxdepth 3 -type f
```

Не удаляйте исходные учебные файлы.
