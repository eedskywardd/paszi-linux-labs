# 7. Самостоятельная мини-задача

Теперь выполните несколько действий самостоятельно.

## Шаг 1. Убедитесь, где вы находитесь

Выполните:

```bash
pwd
```

Текущий каталог сейчас не важен, потому что дальше мы сначала перейдём в нужное место.

## Шаг 2. Перейдите в рабочий каталог

```bash
cd /root/bash03
```

Проверьте:

```bash
pwd
```

Должно быть:

```text
/root/bash03
```

## Шаг 3. Создайте каталог `final`

Каталога `final` пока может не быть. Создайте его самостоятельно.

После создания **зайдите внутрь `final`** и ещё раз проверьте себя командой `pwd`.

Правильный путь:

```text
/root/bash03/final
```

## Что должно получиться внутри `final`

1. Файл `conf_files.txt` — отсортированный список **всех файлов `.conf`** внутри `/root/bash03/lab`.
2. Копия файла:
   ```text
   /root/bash03/lab/permissions/run.sh
   ```
   с именем:
   ```text
   run_copy.sh
   ```
3. Для `run_copy.sh` установите права:
   ```text
   700
   ```
4. Создайте скрытый пустой файл:
   ```text
   .done
   ```

Проверьте результат:

```bash
pwd
ls -la
cat conf_files.txt
stat -c "%a %n" run_copy.sh
```

Понадобятся команды `mkdir`, `cd`, `find`, `sort`, `cp`, `chmod`, `touch`.

```bash

```

Результат можно передать в `sort`, а затем сохранить через `>`.

</details>


Остальные имена подставьте самостоятельно.

</details>
