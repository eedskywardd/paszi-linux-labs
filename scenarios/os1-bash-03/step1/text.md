# 1. Абсолютный и относительный путь

## Абсолютный путь

Абсолютный путь начинается с символа `/` и полностью описывает, где находится объект.

Например:

```text
/root/bash03/lab/projects/site/index.html
```

Такой путь работает независимо от того, где вы сейчас находитесь.

Перейдите в каталог сайта:

```bash
cd /root/bash03/lab/projects/site
```

Проверьте:

```bash
pwd
```

Должно быть:

```text
/root/bash03/lab/projects/site
```

Теперь сохраните текущий путь в отдельный файл:

```bash
pwd > /root/bash03/step1_pwd.txt
```

Проверьте:

```bash
cat /root/bash03/step1_pwd.txt
```

## Относительный путь

Когда вы уже находитесь в `site`, можно написать:

```bash
cat index.html
```

Вместо полного:

```bash
cat /root/bash03/lab/projects/site/index.html
```

Имя `index.html` здесь является относительным путём — оно рассматривается относительно текущего каталога.

Нажмите **CHECK**.
