# Этап 2. Доступ к заказам выдан не тому сотруднику

Проверьте таблицу `training.orders`.

**Ожидаемый результат:**
- `checker` может читать заказы;
- `seller` не может читать заказы;
- никто из этих двух ролей не может добавлять, изменять или удалять заказы;
- право `seller` читать каталог `training.products` сохраняется.

Сначала оцените текущие права и выберите минимальные изменения.

<details><summary>Подсказка 1</summary>Право на чтение одной таблицы не даёт права на другую таблицу автоматически.</details>
<details><summary>Подсказка 2</summary>Здесь нужно одновременно выдать одно право и отозвать другое.</details>
<details><summary>Подсказка 3</summary>В мини-конспекте есть команды GRANT и REVOKE. Найдите в них место для ролей и таблиц вашей базы.</details>

После успешной автоматической проверки работа заканчивается.
