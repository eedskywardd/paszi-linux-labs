# Этап 1. Продавцу нужен каталог товаров

У сотрудника с ролью `seller` нет возможности читать `training.products`.

**Ожидаемый результат:** роль `seller` может выполнить SELECT из `training.products`, но не получает INSERT, UPDATE и DELETE.

Сначала изучите права командой `\\dp training.*`. Не меняйте данные товаров и не выдавайте дополнительных прав.

<details><summary>Подсказка 1</summary>Проверьте, какие права уже есть у роли seller на таблицу products.</details>
<details><summary>Подсказка 2</summary>Нужна команда для выдачи разрешения, а не для изменения записей.</details>
<details><summary>Подсказка 3</summary>В конспекте есть форма GRANT SELECT ON имя_таблицы TO имя_роли; используйте нужные объекты вашей учебной базы.</details>

После настройки нажмите **ПРОВЕРИТЬ**.
