# Готово: первая практика Bash завершена

За это занятие вы не просто посмотрели команды, а использовали их в настоящем Linux-терминале.

## Что вы уже умеете

| Команда / символ | Назначение |
|---|---|
| `whoami` | кто текущий пользователь |
| `pwd` | где я нахожусь |
| `ls` | что находится в каталоге |
| `ls -l` | подробный список |
| `ls -la` | подробный список + скрытые объекты |
| `cd` | перейти в другой каталог |
| `mkdir` | создать каталог |
| `touch` | создать пустой файл |
| `echo` | вывести текст |
| `cat` | прочитать текстовый файл |
| `cp` | копировать |
| `mv` | переместить или переименовать |
| `rm -i` | удалить с подтверждением |
| `>` | записать вывод заново |
| `>>` | дописать вывод в конец |
| `*` | маска: любая последовательность символов |

## Пять вещей, которые нужно запомнить

1. Bash — это командная оболочка, а терминал — окно для работы с ней.
2. Команды и имена в Linux чувствительны к регистру.
3. Перед изменением файлов полезно проверить `pwd` и `ls`.
4. `>` и `>>` — не одно и то же.
5. Удаление через терминал требует внимательности; на обучении используйте `rm -i`.
