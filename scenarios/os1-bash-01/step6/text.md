# 6. Ключи, скрытые файлы и маска `*`

Вы уже видели ключи `-l`, `-p`, `-i`.

Одна команда может иметь разные ключи.

### Обычный список

```bash
cd /root/bash01/work/docs
ls
```

### Подробный список

```bash
ls -l
```

### Скрытые объекты

Создайте скрытый файл:

```bash
touch .secret.txt
```

Обычный `ls` его обычно не показывает:

```bash
ls
```

А ключ `-a` означает показать также скрытые объекты:

```bash
ls -la
```

В Linux имя, начинающееся с точки, считается скрытым.

## Маска `*`

Создайте ещё три файла:

```bash
touch one.txt
touch two.txt
touch photo.jpg
```

Команда:

```bash
ls *.txt
```

покажет имена, которые заканчиваются на `.txt`.

Символ `*` означает: **любая последовательность символов**.

Теперь скопируйте все обычные `.txt` из `docs` в `backup` одной командой:

```bash
cp *.txt ../backup/
```

Проверьте:

```bash
ls ../backup
```

`one.txt` и `two.txt` должны попасть в backup, а `photo.jpg` — нет.

Нажмите **CHECK**.
