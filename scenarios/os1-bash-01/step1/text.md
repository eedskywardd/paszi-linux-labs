# 1. Терминал, shell и первая команда

Начнём с команд, которые ничего опасного не меняют.

### Кто я?

```bash
whoami
```

`whoami` выводит имя текущего пользователя.

### Где я?

```bash
pwd
```

`pwd` = **print working directory** — показать полный путь текущего каталога.

### Вывести текст

```bash
echo "Hello Bash"
```

`echo` просто выводит текст.

Теперь впервые сохраним результат команды в файл:

```bash
echo "BASH_OK" > /root/bash01_hello.txt
```

Здесь:

- `echo "BASH_OK"` создаёт текст;
- `>` направляет вывод не на экран, а в файл;
- `/root/bash01_hello.txt` — полный путь к файлу.

Проверьте содержимое:

```bash
cat /root/bash01_hello.txt
```

`cat` выводит содержимое текстового файла.

**Ожидаемый результат:**

```text
BASH_OK
```

Когда увидели результат, нажмите **CHECK**.
