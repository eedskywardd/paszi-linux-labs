# 7. Самостоятельная мини-задача

Теперь несколько действий **без готовой последовательности команд**.

Сначала перейдите в рабочий каталог:

```bash
cd /root/bash01/work
```

Каталога `final` пока **нет — это нормально**. Создайте его:

```bash
mkdir final
```

Теперь войдите в созданный каталог:

```bash
cd final
```

Если попробовать выполнить `cd final` **до** команды `mkdir final`, терминал выдаст ошибку `No such file or directory`.

Уже внутри каталога `final` создайте файл `answer.txt` с **двумя строками**:

```text
I know pwd
I know ls
```

Затем:

1. создайте копию этого файла с именем `answer_copy.txt`;
2. создайте скрытый пустой файл `.done`;
3. проверьте результат через `ls -la` и `cat`.

Итог должен выглядеть по смыслу так:

```text
final/
├── .done
├── answer.txt
└── answer_copy.txt
```

<details>
<summary>Подсказка 1: какие команды понадобятся?</summary>

Вам уже встречались `mkdir`, `echo`, `>`, `>>`, `cp`, `touch`, `ls -la`, `cat`.

</details>

<details>
<summary>Подсказка 2: как сделать две строки?</summary>

Первую строку запишите через `>`, вторую добавьте через `>>`.

</details>

<details>
<summary>Подсказка 3: почти готовая схема</summary>

Вы уже должны находиться в `/root/bash01/work/final`.

```bash
echo "..." > answer.txt
echo "..." >> answer.txt
cp answer.txt ...
touch ...
```

Подставьте недостающие имена самостоятельно.

</details>

Когда всё готово — нажмите **CHECK**.
