# 7. Самостоятельная мини-задача

Теперь несколько действий **без готовой последовательности команд**.

Создайте внутри:

```text
/root/bash01/work
```

каталог:

```text
final
```

Внутри него должен быть файл `answer.txt` с **двумя строками**:

```text
I know pwd
I know ls
```

Затем:

1. создайте копию этого файла с именем `answer_copy.txt`;
2. создайте скрытый пустой файл `.done`;
3. проверьте результат через `ls -la` и `cat`.

Итог должен выглядеть по смыслу так:

```text
final/
├── .done
├── answer.txt
└── answer_copy.txt
```

<details>
<summary>Подсказка 1: какие команды понадобятся?</summary>

Вам уже встречались `mkdir`, `echo`, `>`, `>>`, `cp`, `touch`, `ls -la`, `cat`.

</details>

<details>
<summary>Подсказка 2: как сделать две строки?</summary>

Первую строку запишите через `>`, вторую добавьте через `>>`.

</details>

<details>
<summary>Подсказка 3: почти готовая схема</summary>

```bash
cd /root/bash01/work
mkdir ...
echo "..." > ...
echo "..." >> ...
cp ... ...
touch ...
```

Подставьте нужные имена самостоятельно.

</details>

Когда всё готово — нажмите **CHECK**.
