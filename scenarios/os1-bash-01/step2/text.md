# 2. Где я нахожусь: `pwd`, `ls`, `cd`

В Linux файлы и каталоги образуют дерево.

Самая верхняя точка дерева — корень:

```text
/
```

Домашний каталог текущего пользователя можно обозначить:

```text
~
```

### Смотрим текущий каталог

```bash
pwd
```

### Смотрим, что внутри

```bash
ls
```

`ls` = list — показать содержимое каталога.

### Переходим в корень

```bash
cd /
pwd
```

`cd` = change directory — перейти в другой каталог.

### Возвращаемся домой

```bash
cd ~
pwd
```

Для пользователя root домашний каталог обычно:

```text
/root
```

Теперь создайте отдельное место для всей работы:

```bash
mkdir -p /root/bash01/work
cd /root/bash01/work
pwd
```

`mkdir` создаёт каталог. Ключ `-p` позволяет сразу создать недостающие родительские каталоги.

Последняя команда должна показать:

```text
/root/bash01/work
```

Нажмите **CHECK**.
