# 4. Записываем и читаем текст: `echo`, `cat`, `>`, `>>`

Сейчас `notes.txt` пустой.

Запишем первую строку:

```bash
echo "Operating Systems" > /root/bash01/work/docs/notes.txt
```

Проверьте:

```bash
cat /root/bash01/work/docs/notes.txt
```

Теперь добавим вторую строку:

```bash
echo "Bash practice" >> /root/bash01/work/docs/notes.txt
```

И снова:

```bash
cat /root/bash01/work/docs/notes.txt
```

Должно быть:

```text
Operating Systems
Bash practice
```

### Главное отличие

`>` — записать заново. Старое содержимое файла будет заменено.

`>>` — добавить текст **в конец**, сохранив то, что было раньше.

Проверьте количество строк в файле:

```bash
wc -l < /root/bash01/work/docs/notes.txt
```

Должно появиться:

```text
2
```

`wc -l` считает строки, а символ `<` передаёт команде содержимое указанного файла.

> **Важно:** не вводите просто `wc -l` без файла или без `< путь`. В таком случае команда начнёт ждать текст с клавиатуры и будет казаться, что терминал завис. Чтобы выйти из такого режима, нажмите **Ctrl+D**.
