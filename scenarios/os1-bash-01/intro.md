# Bash с нуля · занятие 1

Это первое занятие для тех, кто **раньше почти не работал в Linux через командную строку**.

Здесь не нужно ничего устанавливать: справа уже запущен настоящий временный Linux-стенд Killercoda.

## Сначала три понятия

**Терминал** — окно, в котором вы вводите текстовые команды.

**Shell (командная оболочка)** — программа, которая читает вашу команду и запускает её.

**Bash** — одна из самых известных командных оболочек Linux. Название расшифровывается как **Bourne Again Shell**.

Упрощённо:

```text
Вы → терминал → Bash → Linux → результат
```

Проверьте оболочку:

```bash
bash --version
```

В первой строке должна быть указана версия GNU bash.

## Как читать приглашение командной строки

В терминале вы можете видеть строку, похожую на:

```text
root@host:~#
```

Это **не команда**. Печатать её не нужно.

- `root` — текущий пользователь;
- `host` — имя компьютера;
- `~` — домашний каталог;
- `#` — приглашение оболочки для администратора root.

Команду пишут **после** этого приглашения и нажимают **Enter**.

## Как устроена команда

Часто команда выглядит так:

```text
команда   ключ   аргумент
ls        -l     /etc
```

- **команда** — что выполнить;
- **ключ / опция** — как именно выполнить;
- **аргумент** — с чем выполнить действие.

Пробелы между частями важны. Linux также различает большие и маленькие буквы: `Docs` и `docs` — разные имена.

На каждом этапе сначала прочитайте объяснение, затем выполните команды в терминале и нажмите **CHECK**.
