# ТФУ №7Б · Ремонт и приёмка

Это вторая часть итоговой работы.

В части 7А вы получили диагностическую карту:

```text
L11=OPEN_WIRE4_22.6M
L12=SPLIT_PAIR
P18=HIGH_RESISTANCE_OR_CCA_LINE
F07=DIRTY_CONNECTOR_172.0M
```

Теперь задача — не искать неисправность заново, а:

1. выбрать корректный способ ремонта;
2. восстановить все четыре сегмента;
3. выполнить контрольные измерения;
4. оформить итоговый акт приёмки.

## Команды

```bash
repair-guide
repair
acceptance-status
```

Если забыли, какой ремонт подходит к конкретному дефекту, сначала выполните:

```bash
repair-guide
```

CHECK в этой части также допускает пробелы вокруг `=` и любой регистр букв.
