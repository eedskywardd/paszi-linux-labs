# 6. Оформить итоговый акт

Создайте итоговый акт:

```bash
nano /root/tfu07b/final-act.txt
```

Шаблон:

```text
COPPER_L11=RESTORED
COPPER_L12=RESTORED
POE_P18=RESTORED
FIBER_F07=RESTORED
ACCEPTANCE=PASS
FINAL_STATUS=OK
```

После заполнения нажмите **CHECK**.

Это последний CHECK по теме диагностики.
