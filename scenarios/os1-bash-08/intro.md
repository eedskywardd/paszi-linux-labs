# ОС08 · Bash: циклы и массовая обработка файлов

В ОС07 скрипт уже умел принимать аргументы и выбирать действия через `if`.

Теперь научим Bash **повторять одно действие много раз автоматически**.

Представьте каталог со 100 файлами. Выполнять одну и ту же команду 100 раз вручную бессмысленно. Для этого существуют циклы.

Сегодня вы изучите:

- цикл `for`;
- переменную цикла;
- арифметический счётчик;
- маски файлов `*.txt`;
- `if` внутри цикла;
- цикл `while read`;
- массовую обработку каталога.

## Подготовка

Проверьте стенд:

```bash
cat /root/BASH08_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/bash08/work
pwd
```

Правильный путь:

```text
/root/bash08/work
```

Учебные файлы находятся здесь:

```text
/root/bash08/data
```

Посмотрите их:

```bash
ls -la /root/bash08/data
```
