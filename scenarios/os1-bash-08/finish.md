# ОС08 завершена

Теперь вы умеете автоматизировать повторяющиеся действия в Bash.

## Новые конструкции

| Конструкция | Назначение |
|---|---|
| `for X in ...; do ... done` | повторить действия для набора значений |
| `*.txt` | выбрать имена по маске |
| `basename` | убрать путь и оставить имя |
| `$((...))` | арифметика Bash |
| `elif` | дополнительная ветка условия |
| `while read -r X` | читать вход построчно |
| `done < file` | передать файл на вход цикла |
| `[[ "$X" == *.txt ]]` | сравнить строку с маской |

## Что изменилось

Раньше вы выполняли одну команду для одного объекта.

Теперь Bash может:

- пройти по целому каталогу;
- проверить каждый объект;
- посчитать разные типы файлов;
- обработать текст построчно;
- автоматически сформировать итоговый отчёт.
