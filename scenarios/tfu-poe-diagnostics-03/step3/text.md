# 3. Проверить линию под нагрузкой

Согласование PoE проходит успешно, а напряжение без нагрузки выглядит нормальным.

Но устройство всё равно не работает.

Проверьте линию под нагрузкой:

```bash
load-test P02
```

Сравните:

- `VOLTAGE IDLE`;
- `VOLTAGE UNDER LOAD`;
- `DROP`.

Запишите напряжение под нагрузкой **только числом**, без `V`:

```bash
echo "НАПРЯЖЕНИЕ" > /root/tfu03/voltage.txt
```

После этого нажмите **CHECK**.
