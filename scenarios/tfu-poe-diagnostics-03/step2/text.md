# 2. Проверить параметры PoE

Теперь проверьте проблемный порт:

```bash
poe-test P02
```

Обратите внимание на:

- стандарт PoE;
- класс потребителя;
- успешность согласования;
- напряжение без нагрузки.

Запишите **номер класса** устройства:

```bash
echo "КЛАСС" > /root/tfu03/poe-class.txt
```

Например, если указано `PD CLASS: 2`, нужно записать только `2`.

Нажмите **CHECK**.
