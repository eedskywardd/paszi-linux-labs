# 1. Найти проблемное PoE-устройство

Начните с общей проверки:

```bash
poe-status
```

Найдите порт, где устройство не получает питание или имеет состояние `FAULT`.

Запишите номер порта:

```bash
echo "PXX" > /root/tfu03/problem-port.txt
```

Проверьте:

```bash
cat /root/tfu03/problem-port.txt
```

После этого нажмите **CHECK**.
