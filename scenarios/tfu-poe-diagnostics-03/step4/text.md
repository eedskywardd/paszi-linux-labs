# 4. Оформить диагноз и восстановить PoE-линию

По результатам измерений нужно оформить технический диагноз.

Создайте:

```bash
nano /root/tfu03/report.txt
```

Шаблон:

```text
PORT=
PD_CLASS=
FAULT=
CAUSE=
```

Названия неисправности и причины возьмите из вывода `load-test P02`.

После заполнения проверьте:

```bash
cat /root/tfu03/report.txt
```

Затем выполните виртуальный ремонт:

```bash
repair-poe P02
```

После ремонта обязательно повторите:

```bash
poe-status
poe-test P02
load-test P02
```

Устройство должно перейти в нормальное состояние, а проверка под нагрузкой — показать `PASS`.

После этого нажмите **CHECK**.
