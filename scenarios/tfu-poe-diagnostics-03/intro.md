# ТФУ №3 · Диагностика PoE-линии

Вы обслуживаете небольшую офисную сеть. Несколько устройств получают питание по Ethernet.

На стенде подключены:

```text
SW1
├── P01 → IP-CAM-01
├── P02 → IP-CAM-02
├── P03 → AP-01
└── P04 → PC-01
```

Поступила заявка:

> **IP-CAM-02 не включается.**

Нужно определить, где проблема: порт, PoE-питание или сама линия.

Виртуальные приборы:

- `poe-status` — состояние PoE-портов;
- `poe-test` — параметры PoE;
- `load-test` — проверка линии под нагрузкой;
- `repair-poe` — виртуальное устранение дефекта.

Главная цель — понять алгоритм диагностики PoE-линии.
