# 1. Разобрать заявки и выбрать приборы

Сначала посмотрите симптомы:

```bash
incident-list
```

Если забыли назначение приборов:

```bash
instrument-guide
```

Создайте план диагностики:

```bash
nano /root/tfu07a/plan.txt
```

Шаблон:

```text
L11=
L12=
P18=
F07=
```

Укажите **минимально необходимый набор приборов** через запятую:

- для L11 нужен тестер и TDR;
- для L12 нужен тестер и проверка пар;
- для P18 — PoE-проверка и нагрузочный тест;
- для F07 — сначала VFL, затем измерение потерь и OTDR.

Названия команд записывайте без параметров, например:

```text
L11=cable-test,tdr
```

После заполнения нажмите **CHECK**.
