# ТФУ №7А · Итоговая диагностика

Это финальная работа по теме диагностики физического уровня.

У вас **четыре независимые аварии**. На этот раз не нужно запускать все приборы подряд — сначала определите симптом, затем выберите подходящий инструмент.

## Объект

```text
PC-11 ── L11 ──┐
PC-12 ── L12 ──┤
AP-03 ── P18 ──┤ SW1 ══ F07 ══ SW2
               │
               └── серверная
```

### Заявки

1. **PC-11:** Link отсутствует.
2. **PC-12:** Link есть, но скорость упала до 100 Mbps и растут ошибки.
3. **AP-03:** точка доступа периодически перезапускается.
4. **F07:** оптический uplink работает, но ошибки и потери выше нормы.

## Команды стенда

Перед началом выполните:

```bash
instrument-guide
incident-list
```

`instrument-guide` напомнит назначение приборов.  
`incident-list` покажет исходные симптомы.

### Важно

- Все значения для файлов берите **из вывода приборов**.
- Числа записывайте без единиц измерения.
- CHECK допускает пробелы вокруг `=` и любой регистр букв.
- Если CHECK не проходит, он пишет, **какое именно поле неверно**.
