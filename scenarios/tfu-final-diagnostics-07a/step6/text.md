# 6. Собрать диагностическую карту

Теперь соберите все четыре диагноза в один файл:

```bash
nano /root/tfu07a/diagnostic-card.txt
```

Шаблон:

```text
L11=OPEN_WIRE4_22.6M
L12=SPLIT_PAIR
P18=HIGH_RESISTANCE_OR_CCA_LINE
F07=DIRTY_CONNECTOR_172.0M
```

Здесь уже **ничего придумывать не нужно** — просто сверьте результаты предыдущих этапов.

После заполнения нажмите **CHECK**.
