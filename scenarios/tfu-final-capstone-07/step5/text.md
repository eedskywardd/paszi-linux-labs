# 5. Рассчитать бюджет оптической линии F02

Получите исходные данные:

```bash
fiber-budget-data
```

Формулы:

```text
Потери волокна = длина (км) × затухание (dB/км)
Потери коннекторов = количество × потери одного коннектора
Потери сварок = количество × потери одной сварки

Общие потери =
потери волокна + коннекторы + сварки + инженерный запас

RX = мощность передатчика - общие потери
```

Округляйте итоговые значения до **двух знаков после точки**.

Создайте:

```bash
nano /root/tfu07/budget.txt
```

Шаблон:

```text
FIBER_LOSS=
CONNECTOR_LOSS=
SPLICE_LOSS=
TOTAL_LOSS=
RX_POWER=
RESULT=
```

Для RESULT используйте `PASS` или `FAIL`.

После заполнения нажмите **CHECK**.
