# 7. Найти неисправность PoE-линии P07

CAM-02 периодически перезапускается.

Проверьте PoE-согласование:

```bash
poe-test P07
```

Затем проверьте линию **под нагрузкой**:

```bash
load-test P07
```

Создайте:

```bash
nano /root/tfu07/poe-fault.txt
```

Шаблон:

```text
FAULT=
CAUSE=
```

После заполнения нажмите **CHECK**.
