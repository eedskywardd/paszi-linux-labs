# 2. Спроектировать медные линии

Выберите решения для трёх типов медных подключений.

Условия:

- рабочие места: 25–72 м, обычная офисная среда;
- AP: 64 и 81 м, требуется PoE;
- CAM-03: 69 м, PoE, рядом силовая трасса.

Используйте варианты:

```text
CAT6_UTP
CAT6_UTP_POE
CAT6A_FTP_POE
```

Создайте:

```bash
nano /root/tfu07/copper-design.txt
```

Шаблон:

```text
OFFICE=
AP=
CAM03=
```

После заполнения нажмите **CHECK**.
