# ОС05 · macOS: интерфейс, Finder и System Settings

Это первая из двух практических работ по macOS.

Для этой работы понадобятся **три вкладки браузера**:

1. эта страница Killercoda — здесь находятся задания и CHECK;
2. ThanasOS — интерактивная браузерная оболочка в стиле macOS;
3. osimulator — тренажёр структуры System Settings.

## Откройте симуляторы

**ThanasOS:**

https://thanasos.thanas.dev

**System Settings simulator:**

https://osimulator.com/

> Это независимые учебные веб-симуляторы, а не настоящий компьютер Apple. Они нужны для изучения расположения элементов интерфейса и логики работы macOS.

## Как выполняется работа

Действия вы выполняете в симуляторе, а ответы фиксируете в терминале Killercoda. После каждого этапа нажимаете **CHECK**.

Проверим, что рабочая среда готова:

```bash
cat /root/OS05_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/os05/work
pwd
```

Должно быть:

```text
/root/os05/work
```

Не закрывайте вкладку с симулятором до конца работы.
