# 3. Код возврата команды: `$?`

После выполнения команды Bash запоминает специальное число — **код возврата**.

Посмотреть его можно через:

```bash
echo $?
```

Главное правило:

- `0` — команда завершилась успешно;
- любое другое число — произошла ошибка или команда сообщила о неуспешном результате.

## Успешная команда

Выполните:

```bash
ls /etc/passwd
echo $?
```

Файл существует, поэтому второе значение должно быть:

```text
0
```

Повторите и сохраните код сразу после команды:

```bash
ls /etc/passwd > /dev/null
echo $? > /root/bash07/work/success_code.txt
```

## Неуспешная команда

Теперь специально обратимся к несуществующему пути:

```bash
ls /root/bash07/NO_SUCH_FILE
echo $?
```

Появится сообщение об ошибке, а код будет **не 0**.

Сохраним только код:

```bash
ls /root/bash07/NO_SUCH_FILE > /dev/null 2>&1
echo $? > /root/bash07/work/failure_code.txt
```

Здесь:

- `> /dev/null` скрывает обычный вывод;
- `2>&1` туда же направляет сообщение об ошибке.

Сейчас не нужно запоминать `2>&1` подробно. Для этой работы достаточно понимать: мы скрыли текст ошибки, чтобы сохранить только код.

Проверьте:

```bash
cat /root/bash07/work/success_code.txt
cat /root/bash07/work/failure_code.txt
```

Первый файл должен содержать `0`, второй — ненулевое число.

Нажмите **CHECK**.
