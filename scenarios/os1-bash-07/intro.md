# ОС07 · Bash: аргументы, условия и коды возврата

В ОС06 вы создали свой первый Bash-скрипт.

Но тот скрипт всегда выполнял одно и то же.

Теперь научим скрипт:

- принимать данные при запуске;
- понимать, сколько данных ему передали;
- узнавать, успешно ли выполнилась команда;
- проверять существование файлов и каталогов;
- принимать решение через `if`;
- возвращать разные результаты в зависимости от ситуации.

## Пример того, к чему мы придём

Вместо скрипта, который всегда работает одинаково:

```bash
./filecheck.sh
```

мы сможем передавать ему путь:

```bash
./filecheck.sh /root/bash07/data/sample.txt
```

И скрипт сам решит, существует файл или нет.

## Подготовка

Проверьте стенд:

```bash
cat /root/BASH07_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/bash07/work
pwd
```

Должно быть:

```text
/root/bash07/work
```

В учебных примерах уже подготовлен файл:

```text
/root/bash07/data/sample.txt
```

В нём ровно **3 строки**.
