# 1. Аргументы скрипта: `$0`, `$1` и `$2`

До этого данные были записаны прямо внутри скрипта.

Теперь передадим их при запуске.

Создайте:

```bash
cd /root/bash07/work
nano args.sh
```

Введите:

```bash
#!/usr/bin/env bash

echo "SCRIPT=$0"
echo "FIRST=$1"
echo "SECOND=$2"
```

Сохраните файл и сделайте его исполняемым:

```bash
chmod +x args.sh
```

Запустите:

```bash
./args.sh Ivan 18
```

Вы должны увидеть примерно:

```text
SCRIPT=./args.sh
FIRST=Ivan
SECOND=18
```

## Что здесь произошло

Команда запуска:

```text
./args.sh Ivan 18
│         │    │
│         │    └── второй аргумент
│         └─────── первый аргумент
└──────────────── сам скрипт
```

Внутри Bash:

- `$0` — как был запущен сам скрипт;
- `$1` — первый аргумент;
- `$2` — второй аргумент.

Сохраните вывод:

```bash
./args.sh Ivan 18 > args_output.txt
```

Проверьте:

```bash
cat args_output.txt
```

Нажмите **CHECK**.
