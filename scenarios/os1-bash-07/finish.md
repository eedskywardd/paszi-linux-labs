# ОС07 завершена

Теперь ваши Bash-скрипты умеют **получать данные и принимать решения**.

## Новые конструкции

| Конструкция | Назначение |
|---|---|
| `$0` | имя / путь запуска скрипта |
| `$1`, `$2` | первый и второй аргументы |
| `$#` | количество переданных аргументов |
| `$?` | код возврата последней команды |
| `0` | успешное выполнение |
| `[ -f "$FILE" ]` | проверить обычный файл |
| `[ -d "$DIR" ]` | проверить каталог |
| `if ...; then` | выполнить действия, если условие истинно |
| `else` | действия для противоположного случая |
| `fi` | завершить конструкцию if |
| `exit 1` | завершить скрипт с кодом ошибки |

## Самая важная идея

Раньше ваши скрипты просто выполняли команды сверху вниз.

Теперь скрипт может спросить:

> Что мне передали? Объект существует? Какой результат получила команда? Что делать дальше?

И выбрать разные действия.
