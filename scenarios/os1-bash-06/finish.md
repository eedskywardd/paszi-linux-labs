# ОС06 завершена

Теперь Bash для вас — уже не только место, куда вводят отдельные команды.

## Вы изучили

| Конструкция | Назначение |
|---|---|
| `NAME=value` | создать переменную |
| `$NAME` | использовать значение |
| `$HOME`, `$USER`, `$SHELL` | системное окружение |
| `printenv` | показать переменные окружения |
| `export` | передать переменную дочернему процессу |
| `$(команда)` | подставить вывод команды |
| `alias` | короткое имя команды |
| `source файл` | выполнить команды файла в текущей оболочке |
| `#!/usr/bin/env bash` | указать Bash как интерпретатор |
| `chmod +x` | разрешить запуск файла |
| `./script.sh` | запустить скрипт из текущего каталога |

## Главное

Скрипт позволяет записать последовательность команд один раз и затем выполнять её как программу.
