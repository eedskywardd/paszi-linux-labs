# 7. Самостоятельная мини-задача: `info.sh`

Теперь создайте скрипт почти самостоятельно.

Перейдите в рабочий каталог:

```bash
cd /root/bash06/work
```

Создайте каталог:

```text
final
```

и зайдите внутрь него.

Правильный путь:

```text
/root/bash06/work/final
```

Создайте файл:

```text
info.sh
```

## Требования к скрипту

Первая строка:

```bash
#!/usr/bin/env bash
```

Дальше скрипт должен самостоятельно получить значения через подстановку команд и вывести **ровно 4 строки**:

```text
USER=<текущий пользователь>
HOST=<имя компьютера>
KERNEL=<версия ядра>
HOME=<домашний каталог>
```

Для первых трёх значений используйте:

- `whoami`;
- `hostname`;
- `uname -r`.

Для домашнего каталога используйте переменную окружения `$HOME`.

После создания:

1. сделайте `info.sh` исполняемым;
2. запустите его;
3. сохраните вывод в `result.txt`;
4. создайте скрытый файл `.done`.

## Подсказка

Можно сначала сохранить результаты команд в переменные:

```bash
USER_NAME=$(whoami)
```

а потом вывести:

```bash
echo "USER=$USER_NAME"
```

## Проверка перед CHECK

```bash
pwd
ls -la
cat info.sh
cat result.txt
wc -l < result.txt
```

В `result.txt` должно быть **4 строки**.

Нажмите **CHECK**.
