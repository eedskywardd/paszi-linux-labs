# ОС06 · Bash: переменные, окружение, alias и первый скрипт

До этого вы вводили команды по одной.

Теперь Bash начнёт работать как настоящая оболочка: мы будем **сохранять значения в переменных, использовать окружение и объединять команды в собственный файл-скрипт**.

Сегодня:

| Конструкция | Назначение |
|---|---|
| `NAME=value` | создать переменную |
| `$NAME` | получить значение переменной |
| `$HOME`, `$USER`, `$SHELL` | переменные окружения |
| `export` | передать переменную дочерним процессам |
| `$(команда)` | подставить результат команды |
| `alias` | создать короткое имя для команды |
| `#!/usr/bin/env bash` | указать интерпретатор скрипта |
| `chmod +x` | разрешить выполнение файла |

## Подготовка

Проверьте стенд:

```bash
cat /root/BASH06_READY
```

Должно быть:

```text
READY
```

Перейдите в рабочий каталог:

```bash
cd /root/bash06/work
pwd
```

Должно быть:

```text
/root/bash06/work
```
