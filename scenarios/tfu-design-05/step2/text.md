# 2. Выбрать медные линии

Для L01, L02 и L03 выберите кабель.

Учитывайте:

- длину;
- необходимость PoE;
- наличие электромагнитных помех;
- условия офисной прокладки.

Используйте один из вариантов:

```text
CAT6_UTP
CAT6_UTP_POE
CAT6A_FTP_POE
```

Создайте:

```bash
nano /root/tfu05/copper.txt
```

Шаблон:

```text
L01=
L02=
L03=
```

После заполнения нажмите **CHECK**.
