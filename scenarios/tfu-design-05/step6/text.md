# 6. Финальная инженерная проверка

Соберите итоговый проект в одном файле.

Создайте:

```bash
nano /root/tfu05/final.txt
```

Шаблон:

```text
L01=
L02=
L03=
F01=
F02=
PATCH_PANEL=
RACK=
```

Перенесите сюда свои решения из предыдущих этапов.

После этого выполните:

```bash
design-check
```

Если проект собран правильно, вы увидите:

```text
✓ Проект физического уровня прошёл проверку.
```

Затем нажмите **CHECK**.
