# 5. Собрать спецификацию СКС

Теперь нужно собрать базовую спецификацию шкафа.

Известно:

- 12 рабочих мест в кабинете 101;
- 1 точка доступа;
- 1 IP-камера;
- нужен запас портов;
- в шкафу должна быть организована коммутация.

Для этой работы выберите:

- патч-панель;
- стойку/шкаф;
- патч-корды;
- кабельный менеджмент;
- оптический кросс.

Создайте:

```bash
nano /root/tfu05/spec.txt
```

Шаблон:

```text
PATCH_PANEL=
RACK=
PATCH_CORDS=
CABLE_MANAGER=
OPTICAL_CROSS=
```

Допустимые значения:

```text
24_PORT
YES
14
```

Для трёх логических полей используйте `YES`.

После заполнения нажмите **CHECK**.
