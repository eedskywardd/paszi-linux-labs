# 4. Выбрать PoE и активные компоненты

Теперь определите, каким устройствам требуется питание по Ethernet.

По схеме:

- AP-01 — точка доступа;
- CAM-01 — IP-камера;
- рабочие ПК не питаются по PoE.

Создайте:

```bash
nano /root/tfu05/poe.txt
```

Шаблон:

```text
AP01_POE=
CAM01_POE=
PC_POE=
SFP_F01=
SFP_F02=
```

Используйте значения:

```text
YES
NO
MM
SM
```

После заполнения нажмите **CHECK**.
