# Этап 3. Аудит

Создайте разрешённый запрос на TCP/8000 и запрещённую попытку соединения на TCP/9000. Проверьте наличие правила counter log prefix PASZI_DROP: drop. Сформируйте `/root/paszi_report.txt` со строками STUDENT=Фамилия Имя, FAULTS=описание исправленных ошибок, POLICY=объяснение политики запрета по умолчанию. Сохраните отчёт и скриншот успешной проверки.
