# 4. Проверить оптические магистрали

Проверьте обе магистрали:

```bash
certify-fiber A-F01
certify-fiber A-F02
```

Для каждой линии убедитесь в соответствии:

- типа волокна;
- коннекторов;
- типа SFP;
- длины;
- оптических потерь;
- непрерывности.

Создайте:

```bash
nano /root/tfu10/fiber-test.txt
```

Шаблон:

```text
F01_TYPE=
F01_SFP=
F01_LOSS=
F01_RESULT=
F02_TYPE=
F02_SFP=
F02_LOSS=
F02_RESULT=
```

Потери укажите числами без единиц измерения.

После заполнения нажмите **CHECK**.
