# 7. Оформить протокол испытаний

На основании всех выполненных проверок оформите итоговый протокол.

Создайте:

```bash
nano /root/tfu10/protocol.txt
```

Шаблон:

```text
PROJECT_COMPLIANCE=
COPPER_LINES=
POE_LINES=
FIBER_F01=
FIBER_F02=
LABELING=
PORT_CAPACITY=
DOCUMENTATION=
FINAL_ACCEPTANCE=
```

Если все предыдущие испытания прошли успешно, используйте `PASS`.

После заполнения нажмите **CHECK**.
