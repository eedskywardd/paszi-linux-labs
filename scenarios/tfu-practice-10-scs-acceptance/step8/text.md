# 8. Выполнить итоговую приёмку

Теперь выполните итоговую команду:

```bash
accept-scs
```

Если все проверки и протокол оформлены правильно, вы увидите:

```text
SCS ACCEPTANCE TEST

Project compliance: PASS
Copper cabling: PASS
PoE infrastructure: PASS
Fiber backbone F01: PASS
Fiber backbone F02: PASS
Port capacity: PASS
Labeling: PASS
Documentation: PASS

FINAL RESULT: ACCEPTED
```

После этого нажмите **CHECK**.

Это и есть итоговая приёмка СКС.
