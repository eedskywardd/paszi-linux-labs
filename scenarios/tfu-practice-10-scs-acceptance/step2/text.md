# 2. Сертифицировать медные линии

Проверять все 18 линий вручную не требуется. Для приёмки возьмите контрольные точки:

- первая линия кабинета 101;
- последняя линия кабинета 101;
- первая линия кабинета 102;
- последняя линия кабинета 102.

Выполните:

```bash
certify-copper A-PC-01
certify-copper A-PC-10
certify-copper A-PC-11
certify-copper A-PC-18
```

Для каждой линии оцените:

- категорию;
- wiremap;
- целостность пар;
- длину;
- соответствие ограничению 100 м.

Создайте:

```bash
nano /root/tfu10/copper-test.txt
```

Шаблон:

```text
A-PC-01=
A-PC-10=
A-PC-11=
A-PC-18=
CATEGORY=
MAX_LENGTH_OK=
RESULT=
```

Используйте `PASS`, категорию `CAT6` и `YES` для проверки длины.

После заполнения нажмите **CHECK**.
