# 4. Убираем повторы: `uniq`

Команда `uniq` умеет убирать **соседние** одинаковые строки.

Попробуйте:

```bash
uniq users.txt
```

Вы заметите, что не все повторы исчезли. Почему? Потому что одинаковые имена в исходном файле стоят не рядом.

Поэтому `uniq` часто используют после `sort`.

## Первая цепочка команд

```bash
sort users.txt | uniq
```

Здесь результат `sort` передаётся через `|` команде `uniq`.

Сохраните уникальные имена:

```bash
sort users.txt | uniq > users_unique.txt
```

Проверьте:

```bash
cat users_unique.txt
```

Должно остаться 4 имени.

## Считаем количество повторов

```bash
sort users.txt | uniq -c
```

Ключ `-c` = **count** — показать, сколько раз встречалась каждая строка.

Сохраните:

```bash
sort users.txt | uniq -c > users_counted.txt
```

Нажмите **CHECK**.
