# 2. Поиск текста: `grep`

`grep` ищет строки, в которых встречается нужный текст.

## Найдём ошибки

```bash
grep "ERROR" app.log
```

Должны появиться три строки.

Сохраните их:

```bash
grep "ERROR" app.log > errors.txt
```

## Найдём слово независимо от регистра

Сначала попробуйте:

```bash
grep "login" app.log
```

Одна запись содержит `login`, а другая — `LOGIN`.

Теперь:

```bash
grep -i "login" app.log
```

Ключ `-i` означает **ignore case** — не различать большие и маленькие буквы.

## Добавим номера строк

```bash
grep -in "login" app.log
```

- `-i` — не учитывать регистр;
- `-n` — показать номер строки.

Сохраните результат:

```bash
grep -in "login" app.log > login_hits.txt
```

Посмотрите:

```bash
cat errors.txt
cat login_hits.txt
```

### Запомните

`grep` **не изменяет файл**. Он только отбирает подходящие строки.

Нажмите **CHECK**.
