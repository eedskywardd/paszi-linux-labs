# 3. Сортировка: `sort`

Посмотрите исходный список:

```bash
cat users.txt
```

Имена идут в случайном порядке и повторяются.

Отсортируйте строки по алфавиту:

```bash
sort users.txt
```

Сохраните результат:

```bash
sort users.txt > users_sorted.txt
```

Проверьте:

```bash
cat users_sorted.txt
```

Теперь обратный порядок:

```bash
sort -r users.txt
```

Ключ `-r` = **reverse** — обратный порядок.

Сохраните:

```bash
sort -r users.txt > users_reverse.txt
```

### Важно

`sort users.txt` не переставляет строки внутри исходного файла. Команда выводит отсортированный результат. Если нужно его сохранить — используем перенаправление `>`.

Нажмите **CHECK**.
