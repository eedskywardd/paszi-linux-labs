# 7. Самостоятельная мини-задача

Теперь соберите небольшой отчёт **без готовой команды целиком**.

Работайте в:

```text
/root/bash02
```

Создайте файл:

```text
final_report.txt
```

Он должен содержать **ровно три строки**:

```text
ERRORS=3
UNIQUE_USERS=4
2026-11-06 09:08 ERROR network unreachable
```

## Откуда взять данные

**Первая строка:** число строк с `ERROR` в `app.log`.

**Вторая строка:** количество уникальных имён в `users.txt`.

**Третья строка:** последняя строка с `ERROR` из `app.log`.

Не считайте руками — получите значения командами.

Вам понадобятся:

`echo`, `grep`, `wc -l`, `sort`, `uniq`, `tail -n 1`, `>`, `>>`, конвейер `|`.

<details>
<summary>Подсказка 1</summary>

Сначала отдельно убедитесь, что команды выводят числа 3 и 4.

</details>

<details>
<summary>Подсказка 2</summary>

Результат команды можно подставить внутрь другой команды конструкцией:

```bash
$(команда)
```

Например:

```bash
echo "COUNT=$(wc -l < users.txt)"
```

</details>

<details>
<summary>Подсказка 3</summary>

Первую строку записывайте через `>`, следующие — через `>>`.

</details>

После создания проверьте:

```bash
cat final_report.txt
```

Если всё совпадает с требуемыми тремя строками — нажмите **CHECK**.
