# Bash с нуля · занятие 2

На прошлом занятии вы познакомились с файлами и каталогами. Теперь научимся **быстро находить нужную информацию внутри текста**.

Это одна из главных причин, почему командная строка полезна: вместо того чтобы глазами просматривать сотни строк, можно попросить Bash и утилиты отобрать только нужное.

Сегодня понадобятся:

| Команда | Для чего |
|---|---|
| `head` | показать начало файла |
| `tail` | показать конец файла |
| `wc` | посчитать строки, слова или символы |
| `grep` | найти строки с нужным текстом |
| `sort` | отсортировать строки |
| `uniq` | убрать соседние повторы |
| `history` | показать историю команд |
| `|` | передать результат одной команды другой |

## Что такое конвейер

Символ:

```text
|
```

называют **pipe — конвейер**.

Пример:

```bash
grep "ERROR" app.log | wc -l
```

Читается так:

1. `grep` находит строки с ERROR;
2. вместо вывода на экран передаёт их через `|`;
3. `wc -l` считает полученные строки.

Получается цепочка:

```text
файл → grep → подходящие строки → wc → число
```

## Подготовка

В терминале выполните:

```bash
cat /root/BASH02_READY
```

Должно быть:

```text
READY
```

Затем:

```bash
cd /root/bash02
ls -l
```

Вы увидите учебные файлы `app.log` и `users.txt`.

Не редактируйте исходные файлы без указания задания.
