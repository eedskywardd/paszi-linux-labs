# 6. История команд и повторное использование

Когда команд становится много, не нужно каждый раз печатать их заново.

## История

```bash
history
```

Команда показывает ранее введённые команды с номерами.

Последние 10 строк истории:

```bash
history | tail -n 10
```

Сохраните их:

```bash
history | tail -n 10 > history_last10.txt
```

## Стрелка ↑

Нажмите клавишу **стрелка вверх** в терминале. Bash подставит предыдущую команду.

Нажимая ↑ несколько раз, можно пройти назад по истории.

Не выполняя опасных изменений, найдите так одну из предыдущих команд `grep` или `sort` и выполните её снова.

## Поиск по истории

В обычном Bash сочетание:

```text
Ctrl + R
```

запускает обратный поиск по истории. После него начните печатать часть команды, например `grep`.

Если в браузерном терминале сочетание перехватывается браузером или работает иначе, просто используйте `history` и стрелки.

Проверьте файл:

```bash
cat history_last10.txt
```

Он должен быть непустым.

Нажмите **CHECK**.
