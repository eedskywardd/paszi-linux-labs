# Bash 02 завершён

Теперь вы умеете не только создавать файлы, но и **обрабатывать текст командами**.

## Новые команды

| Команда | Назначение |
|---|---|
| `head -n 5 file` | первые 5 строк |
| `tail -n 5 file` | последние 5 строк |
| `wc -l file` | количество строк |
| `grep "text" file` | строки с text |
| `grep -i` | поиск без учёта регистра |
| `grep -n` | показывать номера строк |
| `sort` | сортировать строки |
| `sort -r` | обратная сортировка |
| `uniq` | убрать соседние повторы |
| `uniq -c` | посчитать повторы |
| `history` | история команд |
| `|` | передать вывод следующей команде |

## Самая важная идея занятия

Команды Bash можно собирать как конструктор:

```text
получить данные | отфильтровать | отсортировать | посчитать
```

Например:

```bash
grep "ERROR" app.log | tail -n 1
```

Вместо одной огромной команды мы соединяем простые команды, каждая из которых делает одну понятную вещь.
